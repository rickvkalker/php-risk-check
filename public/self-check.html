Check your server directly

The quick check only sees what your site reveals publicly. For a definite answer, run this small script on your own server. It reads the PHP version and settings locally and tells you if you're patched. It changes nothing and attacks nothing.

How to use it

  1. Download php2shell-selfcheck.php
  2. Upload it to your website's public folder (where your homepage lives), using FTP, your hosting file manager, or SSH.
  3. Open it in your browser: https://yoursite.com/php2shell-selfcheck.php
  4. Read the verdict: Patched, Vulnerable, or Critical.
  5. Delete the file when you're done.

No upload access? Check another way

  1. Over SSH, run php -v. The first line shows the version.
  2. In cPanel or Plesk, open the PHP version / "Select PHP Version" tool.
  3. Then ask your host: "Is the 21 October 2026 PHP security fix (php2shell, CVE-2026-109618/109619) installed?" Some hosts patch without changing the version number, so this question settles it.
Only run scripts on servers you own or manage. This script is safe to read before you upload it — open it in a text editor and you'll see it only reads local settings.
